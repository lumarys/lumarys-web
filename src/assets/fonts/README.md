# Fontes para a imagem de compartilhamento

Sora (700) e Inter (400, 600), em WOFF, baixadas do Google Fonts. Servem só ao
renderizador de Open Graph (`src/lib/og.tsx`), que precisa do arquivo bruto no
build; a página usa `next/font`, que cuida das próprias cópias.
